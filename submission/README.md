## Evidence and Limitations

The demo uses synthetic data. Baselines and improvement targets in the proposal
are illustrative, not measured customer results. Orders do not change stock;
payments and invoices are human-confirmed records. Orbyte summaries are
pasted/imported rather than fetched through its API. The Assistant defaults
to review-first writes; explicit Full access retains permission and workflow
checks. Meeting extraction creates tasks for review. Dedicated external-Agent
meeting import is a planned API improvement.
